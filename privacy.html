Privacy Policy

Last updated: 24 November 2026

Personal Keyword Research is a private keyword-analysis project. This policy describes its planned Google Ads API integration and the public informational website. It will be updated if the project's actual data handling changes.

1. Website visitors

This is a static informational website. It has no sign-in form, contact form, analytics scripts or advertising trackers in its own code. The website host may process standard technical information, such as IP addresses and request logs, to operate and secure the site; refer to the hosting provider's own privacy information for details.

2. Google Ads API access

The planned private research workflow uses the Google Ads API to retrieve historical keyword-planning metrics, such as approximate monthly search volume, keyword competition and related planning information. Access is limited to Google Ads accounts that the operator is authorised to use. The intended OAuth scope is https://www.googleapis.com/auth/adwords.

3. How data is used and stored

Keyword metrics are used for personal product and market research, including local analysis and CSV or spreadsheet exports. The tool is not designed to sell account data, build advertising audiences, or make account data publicly available. Credentials and downloaded research data are intended to be handled in the operator's private environment, not on this public website.

4. Sharing and retention

The project does not intentionally share Google Ads account data with unrelated third parties. Google and relevant infrastructure providers may process information as part of their services. Research exports may be retained locally until no longer needed; the public website itself does not store visitor submissions.

5. Security and control

API access uses Google-supported authentication. The operator should safeguard credentials, limit permissions and revoke credentials if necessary. Google account access can be reviewed in the relevant Google account's security settings.

6. Contact and changes

For questions about this project or its data handling, use the developer support email displayed on the Google OAuth consent screen. Any material changes to the project's data use will be reflected here.
